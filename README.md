# Killaura

Клиентский мод для **Minecraft 26.3 (Fabric)**: автоматически наводит камеру на
существо и бьёт его, когда прицел наведён и кулдаун атаки восстановился.
Сделан для приватного сервера с друзьями (AFK-фарм опыта); на публичных
серверах с античитом использовать не стоит — такое палится.

## Управление

- **G** — включить/выключить киллауру (по умолчанию выключена).
- **K** — открыть меню настроек.
- Оба бинда можно переназначить прямо в меню: нажми кнопку бинда, затем клавишу
  (ESC — отмена).

## Меню настроек

| Настройка | Что делает |
|---|---|
| Состояние | вкл/выкл прямо из меню |
| Скорость наводки | насколько быстро поворачивается камера, 5–180 °/тик (меньше = плавнее и «человечнее») |
| Дальность атаки | радиус поиска цели, 1–6 блоков (ванильная дальность удара ~3) |
| Враждебные мобы | зомби, скелеты, крипера и т.д. (вкл по умолчанию) |
| Мирные мобы | коровы, свиньи, овцы, летучие мыши |
| Водные мобы | рыбы, спруты, аксолотли |
| Прочие существа | всё остальное без своей категории |
| Игроки | целимся в игроков (выключено по умолчанию) |
| Не бить переименованных | существа с табличкой имени (клички питомцев) не трогаются |
| Бить только критами | удар только в падении (как ванильный крит: не на земле, набираешь высоту падения, не в воде) и при полностью заряженной шканe |
| Сайлент-ротация | камера не поворачивается вообще: нужный поворот уходит серверу пакетом ровно на момент удара и тут же возвращается обратно |

## Как работает логика

1. Раз в тик ищется цель: живые существа выбранной категории в радиусе дальности
   и с прямой видимостью (рейкаст от глаз). Приоритет — та, что ближе к прицелу.
2. Камера плавно доворачивается к центру хитбокса цели со заданной скоростью.
   При включённой сайлент-ротации доворот считается «виртуально», камера стоит на месте.
3. Удар идёт только когда прицел в 6° от цели, дистанция в пределах дальности и
   шкана атаки заряжена ≥ 90% (в режиме критов — 100% + падение) — то есть полный
   урон, как у обычного клика.
4. Атака выполняется теми же вызовами, что и обычный ЛКМ по мобу (пакет атаки +
   замах руки), кулдаун уважается. Сайлент-ротация: перед ударом серверу
   отправляется пакет поворота на цель, после удара — обратный поворот на
   реальное положение камеры.

Тот же конфиг хранится в `config/killaura.json` (правится и вручную, и из меню).

## Установка

Fabric Loader 0.20.1+ и Fabric API для 26.3, jar из `build/libs/` положить в `mods`.

## Сборка

Нужен JDK 25:

```
gradlew.bat build
```
